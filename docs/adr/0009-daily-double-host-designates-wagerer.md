# The Host designates who wagers on a Daily Double, not the Player who "found" it

The real show's Daily Double is answered by whichever contestant is in control — the one who picked the category and Value. This game has no equivalent: Tiles are always selected by the Host (`selectTile`), never by a Player's own device, so there's no natural "who found it" to fall back on.

Instead, the Host explicitly designates which joined Player wagers, choosable from the full roster regardless of connection status (an offline pick just can't act yet, same as any offline Player). The Host may redesignate freely — a plain mis-click, not a competitive event worth protecting — right up until a wager is actually submitted, after which the Player's choice is final. This keeps the Host in control of the whole Daily Double flow, consistent with how they already drive tile selection and judging everywhere else.
