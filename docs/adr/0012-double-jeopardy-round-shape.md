# Double Jeopardy is a second, optional Round authored upfront and started manually

The Host may choose during Board Setup to give a Game two Rounds — Round 1 at $100–$500, then Double Jeopardy at $200–$1000 — instead of one. All of Double Jeopardy's Categories, Clues, and Daily Doubles are authored and drawn at the same Board-build moment as Round 1's, before the Lobby even opens, rather than the Host getting a second editing pass between Rounds; this keeps Board Setup a single upfront step and keeps Double Jeopardy's Daily Doubles secret from the Host for the same reason Round 1's already are. Double Jeopardy also gets its own Daily Doubles — 2, versus Round 1's 1 — matching the real show. The Host starts Double Jeopardy with an explicit action once every Round 1 Tile is closed; it never starts automatically, consistent with Close and Reveal already being Host-driven rather than triggered by game state alone.
